Open-source control plane for dbt Core

dcp is a self-hostable alternative to commercial dbt Cloud–like ops: projects, jobs, runs, artifacts, lineage, and Elementary — without locking the core to one cloud or orchestrator.

The product is under active development in this repository. This page is the public face until Docker Compose ships.

View on GitHub

Why it exists

Teams that want Cloud-like job and run UX around dbt Core either buy a vendor stack or glue CI, schedulers, and scripts. dcp centralizes that operator workflow and keeps dbt’s model DAG inside dbt.

What v0.1 covers

  • Projects, environments, jobs, and schedules
  • Manual and cron-driven runs with logs and artifacts
  • Basic lineage from dbt artifacts
  • Elementary as required observability
  • Local Docker runner, optional AWS Batch, packaged with Docker Compose

How you run it

You self-host. v0.1 is single-user with no auth — bind it privately. Compose, including a required local dbt runner image, is the packaging target. Nothing here is a hosted SaaS.
